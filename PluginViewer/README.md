# PluginViewer - OpenShot Video Editor Plugin

**PluginViewer** adds a clean **Installed Plug-ins** popout item under OpenShot Video Editor's **Help** menu (**Help $\rightarrow$ 🔌 Installed Plug-ins**) that displays a simple summary of all installed and active plugins.

---

## 🚀 Installation (PowerShell)

```powershell
powershell -ExecutionPolicy Bypass -File "C:\projects\OpenShot_Plugins\PluginViewer\install_plugin.ps1"
```
