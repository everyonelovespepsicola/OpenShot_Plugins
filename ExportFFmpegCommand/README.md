# ExportFFmpegCommand - OpenShot Video Editor Plugin

**ExportFFmpegCommand** is an OpenShot Video Editor plugin that generates and copies the exact standalone `ffmpeg` CLI command line corresponding to your Export settings or active Project Profile.

---

## 🌟 Features

* **Export Window Button:** Injects a **📋 Copy FFmpeg Command** button directly into OpenShot's Export Video dialog.
* **Tools Menu Action:** Access **Tools $\rightarrow$ 📋 Copy FFmpeg Command...** from the main menu bar.
* **1-Click Clipboard Copy:** Copies the complete, ready-to-run FFmpeg string directly to your clipboard for use in PowerShell, CMD, or Terminal.

---

## 🚀 Installation (PowerShell)

```powershell
powershell -ExecutionPolicy Bypass -File "C:\projects\OpenShot_Plugins\ExportFFmpegCommand\install_plugin.ps1"
```
